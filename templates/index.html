Embed on your own websites

Paste this single script tag into the <body> of any website or web application (HTML, React, Next.js, WordPress, etc.). It injects the isolated Shadow DOM popup chat box with zero CSS conflicts! 

<!-- GenZ AI Floating Chatbox Widget -->
<script src="http://127.0.0.1:5000/static/genzai-widget.js" 
        data-server="http://127.0.0.1:5000" 
        data-model="genZai (Custom Trained Model)"
        data-position="bottom-right"
        data-greeting="Hi there! 👋 How can I help you today?" defer></script>

Optional Configuration Attributes:

Attribute Default Description
data-server http://127.0.0.1:5000 Target GenZ AI server URL
data-position bottom-right Floating position (bottom-right or bottom-left)
data-greeting Hi there! 👋 How can I help... Proactive welcome greeting bubble text
